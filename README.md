# Visual Catalog API

A FastAPI project for storing and managing creative visual assets such as:

- Album covers  
- Poster designs  
- Merch concepts  
- AI-generated art  
- Branding visuals  

## 🚀 Features

- Full CRUD operations  
- Search endpoint  
- Filtering by type and tags  
- SQLite database  
- Clean FastAPI + SQLAlchemy structure  
- Docker-ready  
- Render-ready
